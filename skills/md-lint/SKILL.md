# md-lint

封装 `markdownlint-cli2` 的完整工作流。当用户提及"检查 Markdown"、"格式化 MD"、"修复 Markdown 格式"等时触发。

按以下步骤依次执行：确定目标路径、构建排除规则、执行检查、报告结果

## 1. 确定目标路径

### 路径来源

| 用户输入                      | 目标           |
| ----------------------------- | -------------- |
| 未提供路径 / 提供 `.` 或 `..` | 当前工作目录   |
| 提供 1 个或多个路径           | 仅处理这些路径 |

### 路径处理

对每个路径：

| 情况            | 行为                                  |
| --------------- | ------------------------------------- |
| 是目录          | 使用 `"path/**/*.md"` 作为目标        |
| 是 `.md` 文件   | 直接使用该文件                        |
| 不是 `.md` 文件 | 跳过，输出 `非 Markdown 文件，已跳过` |
| 不存在          | 跳过，输出 `路径不存在，已跳过`       |

### 多路径

将所有目标路径合并到**同一条命令**中，减少 npx 启动开销：

```sh
npx --yes markdownlint-cli2 --fix "#.git" "#node_modules" "path1.md" "path2/**/*.md"
```

### 路径转义

- 路径含空格：用双引号包裹

## 2. 构建排除规则

排除规则固定为 `#.git` 和 `#node_modules`

## 3. 执行命令

### 命令模板

```sh
npx --yes markdownlint-cli2 --fix "#.git" "#node_modules" <目标路径...>
```

### 示例

```sh
# 检查 README.md，排除 .git 和 node_modules
npx --yes markdownlint-cli2 --fix "#.git" "#node_modules" "README.md"

# 递归检查 docs/ 目录
npx --yes markdownlint-cli2 --fix "#.git" "#node_modules" "docs/**/*.md"

# 检查整个项目
npx --yes markdownlint-cli2 --fix "#.git" "#node_modules" "**/*.md"
```

## 4. 报告结果

### 判断流程

| 条件                         | 行为               |
| ---------------------------- | ------------------ |
| 命令执行失败（npx 不可用等） | 输出原始错误并停止 |
| 输出包含 MD 规则编号         | 解析为下方表格     |
| 以上皆否                     | 输出 `无格式错误`  |

### 行解析

对每条 lint 输出行提取：

| 字段     | 提取说明            |
| -------- | ------------------- |
| 文件路径 | 行首的文件路径      |
| 行号     | MD 规则前的数字     |
| 规则编号 | 如 `MD001`、`MD009` |
| 描述     | 规则描述文本        |

### 输出格式

```text
| 文件路径 | 行号 | 规则编号 | 描述 |
|---|---|---|---|
| README.md | 10 | MD001 | 标题级别不应递增 |
| docs/guide.md | 25 | MD009 | 行尾不应有空格 |
```

无 lint 问题时输出：

```text
无格式错误（已自动修复）
```

## 约束汇总

| 允许                                    | 禁止                       |
| --------------------------------------- | -------------------------- |
| `npx --yes markdownlint-cli2 --fix ...` | 其他任何命令               |
| `--fix` 自动修复                        | 手动修复未被自动修复的问题 |
| 仅通过命令输出判断结果                  | 在命令输出后读取原始文件   |
