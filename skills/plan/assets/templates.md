# 模板

写入文件前读一次。只填写内容，不增删章节；括号中的说明在完成后删除，不适用的行按说明省略。

## index.md

```markdown
# <需求名>

<三五句话，概括需求本身：做什么、给谁用、有什么约束。可以精简、可以省略细节。不补充需求中没有的内容，不写方案，也不写是否拆分的判断>

## 功能块

| #   | 功能块 | 做完能看到什么 | 依赖 | 文档 |
| --- | ------ | -------------- | ---- | ---- |
| 01  |        |                | -    | -    |
| 02  |        |                | 01   | -    |
```

「文档」列已写好的填链接 `[01](./01.md)`，尚未写文档的填 `-`。

完整示例见 `ai-chat/index.md`。

## 功能块文档

```markdown
# <需求名> / <编号>

<一句话：这块做什么，做完能看到什么>

## 做与不做

| #   | 功能点       | 做与不做 |
| --- | ------------ | -------- |
| 01  | <具体功能点> | 做       |
| 02  | <具体功能点> | 不做     |

备注：<某一角度不适用的原因，或 `不做` 不足 3 条的理由；不写过程、背景与方案；不需要就整段不写>
```

序号按当前表行序从 `01` 起连续编，`做` 行在前、`不做` 行在后；每轮重出整表时按新表重编。备注最多两行，几个角度不适用时合并成一句；只在需要时出现，位置在表格之后，不另起章节。

完整示例见 `ai-chat/01.md`。
