# AI 聊天

单用户和 AI 的聊天，单页，像传统聊天记录那样一问一答，发出去不必等回复。Web 端用 Nuxt 加 Nuxt UI，消息存进表里，调模型时带上最近 7 天的记录并可附加提示词。手机端用安卓壳加 WebView 加载同一网页，单用户认证只要一个密码。

## 功能块

| #   | 功能块           | 做完能看到什么                               | 依赖 | 文档          |
| --- | ---------------- | -------------------------------------------- | ---- | ------------- |
| 01  | 聊天页与消息落库 | 发一句出现自己那条和占位回复，刷新后消息还在 | -    | [01](./01.md) |
| 02  | 接真模型         | 发一句，收到基于 7 天记录的模型回复          | 01   | -             |
| 03  | 单密码登录       | 没登录进不去聊天页，输对密码后一直可用       | 01   | -             |
| 04  | 安卓壳           | 手机上装上 APK，打开就是聊天页               | 01   | -             |
