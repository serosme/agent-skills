# 工作区约束

- 开工前各调一次 `dbx_list_connections` 与 `browse_status`，确认 dbx 与 browse 可用；不可用就说明并降级，不安装、不改 MCP 配置。
- 要用数据库或缓存，一律通过 dbx MCP，连接取 `workspace.md` 基础设施各节的 `connection_id`，不直连、不装客户端、不写脚本绕过。
- `connection_id` 写 `待建` 表示该项未接入，交用户处理；不建连接、不改连接、不删连接。
- 查询默认只读，要写数据先说明语句与影响范围，拿到授权再执行。
- 不代为启动、重启、停止服务，不改端口，不结束进程；需要启动时由用户执行并回报实际地址。
- 地址只取自 `workspace.md` 或实测，不猜端口，不扫端口段，不遍历 `localhost`，不把地址硬编码进代码。
- 探测只允许 `GET` 与 `HEAD` 无副作用路径，超时 3 秒，同一服务最多两次，失败就如实报告，不重复试探。
- 浏览器会话从服务表的地址起步，允许来源也取这里，不用自己记 URL，页面只读，不改用户数据。
- `workspace.md` 只放已坐实的事实。
- 密码原文不写进 `workspace.md` 以外的地方，不进日志、脚本或提交；需要凭据时由用户输入。
- 工作区文件只写根目录，不落进服务仓库；改服务仓库、提交、推送、切分支前先征得用户同意。
