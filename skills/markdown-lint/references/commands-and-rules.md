# 命令与规则细节

本文件是 `markdownlint-cli2` 的调用形式、输出解读与规则处理倾向。
执行流程、边界与验收标准以 `SKILL.md` 为准。

## 可用的调用形式

只使用本机已存在的安装：

| 形式                                                       | 说明                                      |
| ---------------------------------------------------------- | ----------------------------------------- |
| `markdownlint-cli2`                                        | 已全局安装或位于 PATH                     |
| `pnpm exec markdownlint-cli2`                              | 目标仓库本地已安装（`node_modules/.bin`） |
| `node_modules/.bin/markdownlint-cli2`（Windows 为 `.cmd`） | 直接调用仓库本地安装的可执行文件          |

禁止使用（会触发下载或改写环境）：

- `npx markdownlint-cli2`、`pnpm dlx markdownlint-cli2`、`npm exec markdownlint-cli2`
- `npm install` / `pnpm add` / `yarn add`
- `brew install` / `choco install` / `scoop install` / `winget install`

版本与可用参数以本机 `markdownlint-cli2 --version` 和 `--help` 为准，不要凭记忆写死开关名。

## 常用命令形态

```bash
markdownlint-cli2 --version                # 探测是否可用
markdownlint-cli2                          # 用配置里的 globs；没有配置时需显式给路径
markdownlint-cli2 "docs/**/*.md" "*.md"    # 显式指定范围
markdownlint-cli2 --fix "docs/**/*.md"     # 自动修复，只改 Markdown 文件
```

- 记得给 glob 加引号，避免被 shell 提前展开。
- 退出码：0 表示没有发现问题，非 0 表示有问题或工具/配置出错。
  **不要把退出码当唯一判据**，要读输出区分「有问题」和「工具报错」。
- 输出中每条问题形如 `文件:行:列 MDxxx 描述`，报告时原样带上规则与位置。

## 配置发现

- cli2 自己的配置：`.markdownlint-cli2.jsonc` / `.yaml` / `.cjs` / `.mjs`。
- 库的配置：`.markdownlint.json` / `.markdownlint.jsonc` / `.markdownlint.yaml` 等。
- 有配置时尊重其中的规则开关、`globs`、`ignores`；**不修改它们**，
  也不为了让检查通过而临时加忽略或关闭规则。

## 常见规则的处理倾向

`--fix` 能处理的机械问题交给 `--fix`，需要判断的留给用户。
规则编号与描述以工具输出为准；下表只是判断倾向，不是规则全集。

| 规则    | 倾向   | 常见现象                               |
| ------- | ------ | -------------------------------------- |
| `MD009` | 自动修 | 行尾多余空格                           |
| `MD010` | 自动修 | 硬制表符                               |
| `MD012` | 自动修 | 连续多个空行                           |
| `MD022` | 自动修 | 标题前后缺空行                         |
| `MD031` | 自动修 | 围栏代码块前后缺空行                   |
| `MD032` | 自动修 | 列表前后缺空行                         |
| `MD047` | 自动修 | 文件末尾不是单个换行                   |
| `MD048` | 自动修 | 围栏符号风格不统一（` ``` ` 与 `~~~`） |
| `MD049` | 自动修 | 强调符号风格不统一                     |
| `MD050` | 自动修 | 加粗符号风格不统一                     |
| `MD013` | 报告   | 行长度超标；拆行会改变语义或渲染       |
| `MD024` | 报告   | 重复标题；可能是有意的结构             |
| `MD025` | 报告   | 多个一级标题；属于结构问题             |
| `MD033` | 报告   | 行内 HTML；换行、占位符等场景可能必要  |
| `MD036` | 报告   | 用强调当标题；要判断是否该改成标题     |
| `MD040` | 报告   | 围栏代码块缺语言标注；需要选定语言     |
| `MD041` | 报告   | 首行不是一级标题；取决于文件类型       |

## 反馈模板

未安装时：

> 本机未安装 markdownlint-cli2，本次跳过 Markdown 格式检查，也没有尝试安装。
> 需要的话你可以自行安装后再让我复检，我不会代为执行。

存在需要用户决定的问题时：

> 自动修复已完成；`{文件}:{行}:{列}` 仍有 `{规则}`：{描述}。
> {为什么不宜自动改}，请确认怎么处理。

工具报错（不是「有问题」）时：

> `markdownlint-cli2` 执行失败：{原始错误}。
> 未修改任何文件，也没有改动配置；请确认环境或配置后再跑。
