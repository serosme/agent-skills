# agent-skills

## 安装

```bash
npx skills add https://github.com/serosme/agent-skills.git -g -a opencode -y
```

## 技能

- **commit** — 通过分析暂存区更改，生成 Conventional Commits 风格的提交信息
- **md-lint** — 使用 markdownlint-cli2 检测并自动修复 Markdown 文件格式
- **spring-openfeign-client** — 基于 Spring Cloud OpenFeign 封装第三方 HTTP API
